This code snippet demonstrates how to create a full-text index with BM25 scoring enabled for a specified field in a collection. The index configuration includes the field name, type (text), tokenizer (word), lowercasing, and the `scoring` parameter set to the `bm25` scoring type. With scoring enabled, the index records document lengths and term frequencies, so points can be ranked by BM25 relevance to a text query in addition to being filtered.
