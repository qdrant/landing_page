{{/* The interactive three-geometry explorer, served from this repo. Usage: {{< hyperbolic-viewer caption="..." >}} Why a frame rather than inline markup: the viewer's stylesheet sets :root, *, body, a and h1, so inlining it would repaint the article page. The frame isolates it for free. Why this is not the old embed: the page it loads ships in this repo and deploys with the article, so there is no third-party host and no runtime API. Nothing external can take the figure down. How it fails: the static figure is what renders by default. The frame sits transparently on top of it and only takes over once it has loaded, run its script and reported a sane height. So a missing file, a broken script, a failed data fetch, or scripting turned off all leave the reader with exactly the image the article shipped before -- never an empty box. The frame also reports its height, so it never grows an inner scrollbar. The frame is positioned rather than display:none because a display:none iframe gets no layout: its content measures 0, so it reports a height of 8 and can never prove it works. Transparent-but-laid-out is what lets it measure itself while staying invisible. */}} {{- $dir := "/articles_data/hyperbolic-embeddings-qdrant" -}} {{- $cap := .Get "caption" -}} {{- $page := .Get "page" | default "viewer.html" -}} {{- $still := .Get "still" | default "viewer-three-panels.jpg" -}} {{- $h := .Get "height" | default "426" -}} {{/* Cache-bust on the file's own content: browsers hold an iframe URL hard, and a stale frame is indistinguishable from a broken change. */}} {{- $v := slicestr ((printf "static%s/%s" $dir $page) | readFile | md5) 0 8 -}} {{- $alt := .Get "alt" | default (printf "%s %s %s" "The Wheelbarrows category and its parent chain in three panels: a" "hyperbolic Poincare disk where the chain runs straight out from the" "centre, a flat Euclidean layout where it collapses into one cluster, and a text embedding where it scatters.") -}}
