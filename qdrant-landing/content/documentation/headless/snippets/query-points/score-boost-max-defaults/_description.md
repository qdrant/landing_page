The snippet demonstrates how to set a default for a prefetch score that may be missing. A point that is absent from a prefetch's results scores `0.0` for it, which beats every negative score in `max`. The default `-1e30` for `$score[1]` makes such points lose to their real score instead. Use `1e30` with `min`. The `defaults` parameter goes next to `formula`, and its keys need the `$`.
