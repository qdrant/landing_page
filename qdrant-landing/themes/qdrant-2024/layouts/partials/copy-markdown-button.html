{{- /* "Copy as Markdown" button. Copies the page's own Markdown output (the index.md that agents read) rather than converting the rendered HTML, so the clipboard gets the same text an agent would: code snippets in every language, internal links rewritten to their index.md form. copy-markdown.js does the fetch and the copy. Usage: {{ partial "copy-markdown-button.html" . }} or: {{ partial "copy-markdown-button.html" (dict "page" . "glyph" "outline") }} "glyph" "outline" draws the idle icon from the icons/outline set, to match the links next to it in the table of contents. Renders nothing for a page without a Markdown output format. When it does render, it sets the page's hasCopyMarkdown flag, which js.html reads to load copy-markdown.js on exactly the pages that show the button. data-copy-markdown-src is the URL of the Markdown to copy. It is a page today, but the script only cares about the URL, so a button copying a single section can reuse the same markup with a different source. */ -}} {{- $page := . -}} {{- $glyph := "" -}} {{- if reflect.IsMap . -}} {{- $page = .page -}} {{- $glyph = .glyph -}} {{- end -}} {{- with $page.OutputFormats.Get "markdown" -}} {{- $page.Store.Set "hasCopyMarkdown" true -}} {{- end -}}
