{{- /* Returns the names of the shortcodes used on a page, read from the data-shortcode="" marker each shortcode puts on its root element. Reading the rendered .Content, rather than recording a flag in .Page.Store from inside the shortcode, also catches shortcodes that reach the page through {{% include %}}, and is not fooled by Hugo caching a page's content after its first render. Calling .Content here, in , renders the content early; Hugo caches it, so the body reuses the same result. Shortcodes whose output reaches the page some other way than .Content (a layout rendering another page's content directly) are not seen. See assets/shortcodes/README.md. Call with partialCached, keyed by page, so the content is scanned once: partialCached "shortcode-assets/names.html" . .RelPermalink */ -}} {{- $names := slice -}} {{- range findRESubmatch `data-shortcode="([a-z0-9-]+)"` (string .Content) -}} {{- $names = $names | append (index . 1) -}} {{- end -}} {{- return uniq $names -}}
