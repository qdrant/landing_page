# Infrastructure Tools

Manage Qdrant Cloud clusters as code. Both tools use the same provider and authenticate with a [Cloud Management Key](/documentation/cloud-api/#authentication). For a comparison with the `qcloud` CLI and the Cloud API, see [Automate Qdrant Cloud](/documentation/cloud-automation/).

## Cloud Tools

| Integration                         | Description                                                                                 |
| ----------------------------------- | ------------------------------------------------------------------------------------------- |
| [Pulumi](/documentation/cloud-tools/pulumi/)                 | Infrastructure as code tool for creating, deploying, and managing cloud infrastructure      |
| [Terraform](/documentation/cloud-tools/terraform/)           | infrastructure as code tool to define resources in human-readable configuration files.      |
